## 2. Detailed Gap and Risk Analysis

### Gap 1: Schema vs. Code Submission State Mismatch
- **Issue**: Standard DocTypes cannot be submitted via standard Frappe UI (`docstatus` remains 0).
- **Impact**: Standalone helper `calculate_tp_status_for_pass()` looks for `docstatus == 1`, while reporting queries use `docstatus < 2`.
- **Recommendation**: Either enable `is_submittable: 1` on `GRN Note` with standard Submit/Cancel permissions, or align `calculate_tp_status_for_pass()` to match `docstatus < 2`.

### Gap 2: Inactive/Dead Local Procurement Code Footprint
- **Issue**: Hundreds of lines of code and numerous schema fields exist for `Local Paddy Purchase Order`, `is_local_procurement`, and `is_farmer_or_agent`, but controllers actively throw fatal errors whenever they are invoked.
- **Impact**: Increases cognitive load, creates confusion during audits, and clutters the UI unless hidden by scripts.
- **Recommendation**: Formalize whether private purchase is permanently deprecated or slated for future re-enablement.

### Gap 3: Complete Absence of CMR Execution Architecture
- **Issue**: There are no DocTypes to record paddy issued to milling, rice recovery output, bran/husk by-products, delivery dispatch to FCI/OSCSC, or Acceptance Committee (AC) rejection certificates.
- **Impact**: The mill cannot track government CMR obligations, dispatch progress, or reconciliations in the ERP.
